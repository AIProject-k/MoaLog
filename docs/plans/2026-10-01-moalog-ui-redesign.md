# MoaLog UI 전면 개편 (Round 1 · 방향 1a "조용한 갤러리")

작성일: 2026-10-01
디자인 원본: [`design/MoaLog App.dc.html`](../../design/MoaLog%20App.dc.html)이 방향 1a를 전 화면·전 상태로 푼 인터랙티브
프로토타입이고(50개 상태), [`design/MoaLog Round 1.dc.html`](../../design/MoaLog%20Round%201.dc.html)은 두 방향(1a/1b) 시안이다.
둘 다 같은 폴더의 `support.js`로 브라우저에서 열린다. 1b(라이트 종이 톤)는 채택하지 않았다.

## 방침

- **화면을 한 번에 갈아엎는다.** 토큰(색·글꼴·반지름) → 공통 조각 → 화면 순으로 옮겼고, 중간에 컴파일만 유지하던
  `ThemeCompat.kt`(호환 계층)는 모든 화면을 옮긴 뒤 지웠다.
- **디자인 값은 템플릿의 인라인 스타일에서 그대로** 옮긴다(여백·글자 크기·색). 임의로 다듬지 않는다.
- **디자인이 "제안"으로 표시한 것**(앨범 탭 "새 앨범", 영상 막대 위 장면 마커, 설정의 앱 정보)도 구현한다 — 디자인을 채택했으므로 라벨만 뗀다.
- 없는 기능을 그리지 않는다는 `design/DESIGN_REQUEST.md` §9는 그대로 지킨다.
- 커밋은 사용자가 시킬 때만, push는 하지 않는다(`CLAUDE.md`).

## 새로 필요한 동작 (디자인이 요구하지만 기존 앱에 없던 것)

- 날짜 머리글 묶기: 3장 이하인 이웃한 날 → "9월 24일 – 25일" (`core/DayGrouping`, 단위 테스트 12개)
- 월 스크러버 · 월 이동 시트(날짜 미상 줄 포함) · 모아보기를 앨범 상세로 열기
- 토스트 동작("되돌리기"·"앨범 보기") · 앨범 탭에서 빈 앨범 만들기
- 영상 분석 진행 알약 · 설정의 일시정지 사유 + "이어서"
- 검색: 해석 칩 끄기 · 가까운/그 밖의 결과 나누기
- 정리: "이 묶음은 유지" ↔ "다시 보기" 토글

## 확인하며 고친 것

화면을 에뮬레이터에서 디자인 캡처와 나란히 놓고 비교하고(디자인 캡처 51장, 앱 캡처 수십 장), 같은 빌드를 Galaxy S23 실기기
(사진·영상 2,019개)에서 눌러 보며 찾은 것들.

**실기기(S23)에서 찾은 것**

- 영상 마지막 장면 칩("약 0:19")을 누르면 처음부터 재생됨: 마지막 샘플은 `길이 − 1ms`인데 `play()`의 "끝에 가까우면 처음으로"
  규칙이 일부러 건너뛴 경우에도 걸렸다. 장면 칩은 `playHere()`로 그 자리에서 튼다.
- 전체 화면에서 나온 뒤에도 가로로 남음: 폰이 책상에 놓이면 센서가 방향을 정하지 못한다. 나올 때 세로로 맞춘 뒤 1.5초 있다가
  센서에 돌려준다(`FullscreenEffect`).
- 앱을 켤 때마다 "0%" 분석 화면이 0.2초쯤 번쩍임(화면 녹화로 확인): 분석 화면은 첫 분석(AI 태그가 하나도 없을 때)에만 띄운다.
- 월 이동을 해도 그 달이 맨 위로 오지 않음: 새로 읽은 뒤 그 달의 첫 머리글로 스크롤한다.

**에뮬레이터에서 찾은 것**

- 사진을 열었다 닫거나 탭을 오가면 스크롤이 맨 위로 돌아감(옛 앱에도 있던 문제): 화면별 `SaveableStateHolder`로 보던 자리를 지킨다.
  앨범 상세·분류 수정은 앨범마다 따로 기억하고, 뷰어는 열 때마다 새로 시작해야 해서 뺐다.
- 분석 중에 갤러리로 튕김: 새 사진이 들어와 접근 가능한 목록이 바뀔 때마다 `viewerFrom`으로 되돌려 보내던 조건이 뷰어가
  아닌 화면에서도 걸렸다(`refreshBlocking`). 뷰어일 때만 되돌리도록 고쳤다.
- 되돌리기 뒤 앨범 머리글 개수가 그대로: 열어 둔 앨범의 개수·표지를 새로 읽은 값으로 갱신한다.
- 모아보기 카드가 늦게 읽혀 오면 왼쪽 밖에 숨음: `LazyRow`의 항목 키를 뺐다.
- 사진 보기에서 돌아오면 검색 키보드가 또 뜸: 포커스 요청을 한 번만 쓰도록(`consumeSearchFocus`).
- 분석 진행이 32장마다만 갱신됨: 1초마다 알린다. 느린 기기에서 링이 멈춰 보이지 않는다.
- Android 12+ 시작 화면이 흰색으로 번쩍임: 시작 화면 배경을 앱 배경색으로.
- 첫 화면 사진 격자·분석 단계 마커를 디자인 모양(빛 한 점이 있는 그라데이션, 바깥 16dp 둥근 사각)으로.

**접근성**

- 격자 칸이 스크린 리더에 "사진, 2026년 9월 23일" · "동영상 0:31, …, 즐겨찾기" · 선택됨/안 함으로 읽힌다(이전에는 이름이 없었다).
- 설정의 스위치 행 전체가 하나의 `toggleable`이라 켜짐/꺼짐이 읽힌다. 검색 창의 돋보기에 이름을 붙였다.
- S23에서 접근성 트리를 훑어(이름 없는 눌림 요소 · 48dp 미만) 이름 없던 것들을 고쳤다. 정리 탭의 글자 버튼 몇 개
  ("보관 추천 제외하고 선택" · "이걸 보관")는 46dp로 48dp에 약간 못 미친다 — 디자인 값이 44dp라 그대로 뒀다.

**정리**

- 안 쓰는 Gothic A1 글꼴 4개(약 9MB)와 계산용 디버그 로그(`SearchScore`) 삭제.
- 줄바꿈: 디자인의 `text-wrap: pretty`를 `Prose`(끝 두 글자 붙임)로 흉내 냈다.
- README 화면 미리보기를 새 디자인 캡처로 바꿨다(`design/readme/`, 에뮬레이터 데모 사진 · 상태 표시줄 9:41).

## 검증

- 단위 테스트: `:core:test` 97개 · `:app:testDebugUnitTest` 14개(`Prose` 4개 포함) 통과.
- 계측 테스트: 에뮬레이터(API 36)에서 ML 일치 테스트 2개(`ParityTest`·`PrepSplitTest`, 모델 파일을 올려야 돈다)를 뺀 15개 통과.
- 에뮬레이터: 디자인 상태 대부분을 직접 눌러 비교했다 — 첫 실행(권한 → 분석 → 갤러리) · 분석 멈춤/"이어서" · 일부 허용 · 재생 실패
  (잘린 mp4) · 시스템 휴지통 허용/거부 · 글꼴 1.3배. 데모 갤러리는 `eval/dataset`(Wikimedia CC)이며 개인 사진은 쓰지 않았다.
- S23(디버그 빌드, 실제 라이브러리 2,019개): 갤러리 · 앨범 · 앨범 상세(1,300개 폴더) · 분류 수정 · 검색(작년 여름 바다, 장면 칩) ·
  뷰어(두 번 탭 확대 · 아래로 쓸어 닫기 · 좌우 넘기기 · 영상 재생 · 전체 화면) · 정리(240개 선택 막대) · 설정 · 월 이동.
  스크롤 프레임(디버그 빌드): 갤러리 janky 약 9%, p90 17ms / 정리 5%, p90 8ms. 콜드 스타트는 화면 녹화로 확인.
  휴지통·"이 묶음은 유지"·분석 다시 하기처럼 **사용자 데이터를 바꾸는 동작은 S23에서 누르지 않았다**(설정의 분류 항목
  스위치 하나만 껐다 켜서 원래대로 돌려 놓았다).
- **못 한 것 / 한계**
  - S23에서 첫 실행(권한 → 분석)과 일부 허용은 확인하지 않았다 — 앱 데이터를 지우면 2,019개 색인과 즐겨찾기가 사라진다. 에뮬레이터로 대신 봤다.
  - 갤러리에서 연 뷰어는 **불러온 300장 안에서만** 넘어간다("2 / 300"). 옛 앱도 같았고 이번에 손대지 않았다.
  - 월 스크러버는 디자인대로 탭만 된다(끌기 없음). 라이트 테마·가로 화면 레이아웃은 디자인에 없다.
  - S23이 화면 잠금으로 꺼진 뒤에는 이어서 확인하지 못했다.
