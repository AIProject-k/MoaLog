## 3. 이 기준선에서 이미 확인된 결함 (코드 대조)

| ID | 내용 | 위치 |
|---|---|---|
| D-1 | 날짜 조건 검색이 최신 20,000장까지만 본다. 그보다 오래된 사진은 조건과 무관하게 빠진다 | `ui/AppViewModel.kt` (`store.recent(20000)`) |
| D-2 | 태그 조건이 태그당 5,000장까지만 본다 | `ui/AppViewModel.kt` (`photosByTag(t, 5000)`) |
| D-3 | `SearchIndex.indexOf`가 선형 탐색이고, 워커가 `put`하는 동안 UI의 `topK`가 동시에 읽는다. 동기화가 없다 | `core/SearchIndex.kt` |
| D-4 | 모델 신원(`modelId`)이 파일 **길이**로 만들어진다. 복사본이 깨져도 감지하지 않는다 | `AppGraph.kt` |
| D-5 | 기록(이벤트)의 장소명을 채우는 코드가 없다. 지도·검색의 장소 조건이 실제로는 비어 있다 | `core/Events.kt` (`placeName`은 테스트에서만 설정) |

D-1·D-2는 계획서 MLG-101과 일치한다. D-3은 MLG-102와 일치한다. D-4는 MLG-103과 일치한다.
DB 버전은 8이고 계획서 11장의 전제와 같다.
