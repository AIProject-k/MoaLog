## 이번에 정한 것 (바꾸려면 말해 달라)

1. **모델 신원(`modelId`)은 파일 길이 기반 그대로 둔다.** 해시로 바꾸면 기존 사용자의 임베딩이 전부 무효가 되어 1만 장을 다시 분석해야 한다(`Store.checkModel`). 해시는 무결성 검사에만 쓴다. 계획서 MLG-103의 "SHA-256으로 식별"과 다른 결정이다.
2. **백업은 항상 암호화한다.** 평문 옵션은 두지 않았다. 계획서의 "기본 옵션"보다 엄격하다.
3. **짝이 불확실하면 잇지 않는다.** 이름이 없거나, 같은 지문이 여럿이고 폴더로도 못 좁히면 건너뛴다. 못 찾은 사진 수를 복원 결과에 알린다.
4. **복원은 같은 사진·같은 라벨의 교정을 백업 쪽 값으로 덮는다.** 대화상자 문구에 그렇게 적었다.

## 아직 안 한 것

- **MLG-101**: 장소 조건을 실제 데이터에 연결(장소 데이터가 없다 → MLG-501과 함께). "AI 모델 초기화 중" 상태 표시.
- **MLG-104**: Pass 1(메타데이터) 실패는 여전히 바로 영구 실패다. 저장 공간 부족 시 작업 중지와 안내.
- **MLG-105**: 중복 묶음 결정(`dupe_choice`)은 백업·복원하지 않는다. 묶음 키가 사진 번호에서 만들어져서, 지문 기반으로 다시 짜야 한다.
- **CI**: APK를 아티팩트로 올리지 않았다(약 260MB). 브랜치 보호(테스트 실패 시 병합 차단)는 GitHub 설정에서 해야 한다.
- **MLG-001 기기 항목**: 계획서의 사용자 흐름 12개 중 대부분이 **미검증**이다. 기준선 문서에 그대로 적혀 있다.
- **Phase 2 이후**(OCR, 중복 고도화, 얼굴 인식, 장소, 스마트 앨범): 시작하지 않았다.

## 기기 테스트 환경 메모

- 테스트 기기는 `emulator-5558`(MoaLogVideo_API36)이다. 같은 PC에 다른 프로젝트 에뮬레이터(HormoneLog, CouponIt, FaceScope)가 떠 있으니, 모든 `adb`와 `connected*` Gradle 작업에 `ANDROID_SERIAL=emulator-5558`을 붙인다. 아니면 다른 기기에 설치되거나 다른 프로젝트 에뮬레이터를 끌 수 있다.
- instrumented 테스트는 `connectedDebugAndroidTest` 대신 `adb install` 후 `am instrument`로 돌렸다. Gradle이 연결된 기기 전부에 설치하기 때문이다.
- 에뮬레이터 데이터는 `-wipe-data`로 새로 만들었다. 시작 직후 Google 계정 설정 마법사가 뜨면 `settings put global device_provisioned 1`과 `settings put secure user_setup_complete 1`로 건너뛴다.
