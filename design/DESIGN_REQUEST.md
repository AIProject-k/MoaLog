## 0. 한눈에 보기

**요청 한 줄.** 오프라인 AI 사진·영상 갤러리 앱 **MoaLog**(Android)의 디자인을 처음부터 새로 해 주세요.

지금 디자인은 "사진을 자동 분류하는 프로토타입"(9화면, 2026-09-02) 기준입니다. 그 뒤 앱이 **사진+동영상 갤러리 · 말로 찾는 장면 검색 · 중복 정리**까지 커졌는데 디자인은 따라오지 못했습니다(§4).

### 목표 3가지
1. **사진·영상이 주인공인 갤러리.** 앱을 열면 바로 사진이 보이고, 영상은 사진과 섞여 있어도 한눈에 구분됩니다.
2. **AI는 조용히 돕고, 결정은 사람이.** 분류·검색·정리 모두 "보여 주고 → 확인받고 → 되돌릴 수 있게" 설계합니다.
3. **믿을 수 있는 얼굴.** 인터넷 권한이 없는 온디바이스 앱이라는 점이 브랜드·색·글자·아이콘·모션 전체에서 신뢰로 읽혀야 합니다.

### 이번에 새로 들어간 기능 (반드시 반영)
- **동영상 따로 분류.** 앨범을 `전체 / 사진 / 동영상`으로 갈라 볼 수 있습니다. `동영상`을 고르면 앨범 목록 전체가 **영상만으로 다시 분류**됩니다(개수·표지·열었을 때의 내용). 전체 보기에서는 카드에 "영상 13"처럼 영상 수를 함께 보여 줍니다. → §7 `Albums` · `Category`
- **영상 속 장면 찾기.** 말로 찾으면 영상 *파일*이 아니라 **맞은 장면**과 시각("약 0:45 외 2곳")이 나오고, 누르면 그 장면부터 재생됩니다. 결과를 확인한 뒤 앨범으로 모읍니다. → §7 `Search` · `Viewer`

### 진행 방식 (권장)
| 라운드 | 받고 싶은 것 |
|---|---|
| **Round 1** | 서로 다른 방향 **2안** × (디자인 시스템 + 핵심 5화면: `Photos` · `Albums`+`Category` · `Viewer`(사진·영상) · `Search`(결과+확인 모드) · `Cleanup`) |
| **Round 2** | 고른 방향으로 전 화면·전 상태 + 핵심 흐름 프로토타입 + 토큰·컴포넌트 시트 + 앱 아이콘 |

### 꼭 지킬 것 4가지
1. **없는 기능을 그리지 않습니다**(§9). 이전 디자인에는 얼굴 이름·글자 인식 결과가 있었지만 앱에는 없어서 구현할 때 빼야 했습니다.
2. **모든 수치는 dp/sp**로 적습니다(px 금지). 4dp 그리드.
3. **아트보드 이름은 코드의 화면 이름과 1:1**(§12). 이름이 어긋나면 디자인과 코드를 대조할 수 없습니다.
4. **한국어 UI 전용**입니다. 문구는 §8을 그대로 쓰세요.

## 1. 제품 소개

**MoaLog**는 갤러리에 쌓인 사진과 동영상을 **기기 안에서** 분석해 자동 앨범, 한국어 자연어 검색, 영상 속 장면 찾기, 촬영 기록, 중복 정리로 바꿔 주는 Android 앱입니다.

- **온디바이스·오프라인.** 앱은 `INTERNET` 권한을 선언하지 않습니다. 사진·영상·검색어는 어디로도 전송되지 않고, 한국어 CLIP 모델이 앱과 함께 설치됩니다. **이 약속이 제품에서 가장 큰 신뢰 요소**입니다.
- **삭제는 시스템 휴지통으로만.** 앱이 파일을 직접 지우지 않습니다(Android 시스템 확인 → 30일 보관).
- 사용자는 한국어 사용자이고, 갤러리에 사진 수천~수만 장·영상 수십~수천 개가 있으며 스크린샷·메신저 저장 이미지가 많다고 가정합니다.
- 현재 내부 개발 v0.3.x. **폰 세로 화면만** 지원합니다(태블릿·가로 UI는 범위 밖. 영상 전체 화면만 가로).

### 핵심 사용 장면
| # | 사용자가 하려는 일 | 앱이 해 주는 일 |
|---|---|---|
| 1 | "작년 여름 바다 영상 어디 있지?" | 말로 찾기 → 맞은 **장면**부터 재생 → 마음에 드는 것만 골라 앨범으로 |
| 2 | 갤러리 훑어보기 | 날짜순 전체, 월로 점프, 사진 크게 보기·영상 재생 |
| 3 | 앨범 둘러보기 | AI가 만든 분류(음식·반려동물·…)를 사진·동영상 **따로** 보기 |
| 4 | 용량 정리 | 겹치는 사진·영상을 크게 비교하고 보관할 것만 남기기 |
| 5 | 잘못된 분류 고치기 | 다른 앨범으로 옮기기 / 앨범에서 빼기(파일은 그대로) |

## 2. 용어 (이 문서와 UI에서 같은 말로 씁니다)

| 용어 | 뜻 |
|---|---|
| **앨범 4종** | **내 앨범**(직접 만든 모음) · **기기 폴더**(파일이 실제로 저장된 위치: Camera, Screenshots…) · **AI 앨범**(내용으로 묶은 분류: 음식, 반려동물…) · **기록**(촬영 시각으로 묶은 묶음). **즐겨찾기**는 내 앨범 맨 앞의 특수 앨범 |
| **미디어 필터** | `전체 / 사진 / 동영상`. 갤러리·앨범·앨범 상세가 같은 컨트롤을 씁니다 |
| **장면** | 영상의 5초 간격 프레임 하나. 검색은 영상 파일이 아니라 장면을 찾습니다. 시각에는 항상 "약"을 붙입니다 |
| **모아보기** | 갤러리 위쪽의 자동 모음 카드(이번 주 사진·영상, N년 전 오늘) |
| **보관 추천** | 중복 묶음에서 남기라고 권하는 한 장(이유를 함께 적습니다) |
| **빼기 vs 지우기** | **앨범에서 빼기** = 묶음에서만 떼기(파일 그대로). **휴지통으로** = 기기에서 지우기(30일 복구). 두 동작은 시각적으로 확실히 달라야 합니다 |
| **고정** | 사용자가 AI 분류를 확정하는 것. 다시 분석해도 유지됩니다 |

## 3. 디자인 원칙과 톤

1. **사진·영상이 주인공.** UI는 물러서고 콘텐츠가 화면을 채웁니다. 헤더·칩·카드가 콘텐츠보다 먼저 눈에 들어오면 실패입니다.
2. **AI는 제안하고 사람이 결정한다.** 자동 저장은 없습니다. 확인 화면 → 사용자가 빼거나 고름 → 저장. 분류가 틀릴 수 있다는 걸 숨기지 않고, 고치는 길을 가깝게 둡니다.
3. **정직하게 보여 준다.** AI 점수는 확률이 아니므로 확률처럼 보이는 %를 기본 화면에 쓰지 않습니다. 영상 시각은 "약 0:45". 촬영 시각을 모르면 "파일 시각"이라고 밝힙니다. "가장 잘 나온 사진" 같은 단정은 쓰지 않습니다("보관 추천 · 가장 선명함").
4. **지우기는 무겁게, 빼기·숨기기는 가볍게.** 되돌리기 어려운 정도에 비례해 시각적 무게를 줍니다.
5. **프라이버시가 보이게.** "기기 안에서만 처리"가 문구뿐 아니라 표현(아이콘·일러스트·색)으로도 전달되게 합니다.

**톤 키워드.** 담백 · 정돈 · 믿음직 · 따뜻하지만 가볍지 않게. 카피는 존댓말 평서("~합니다", "~하세요"), 짧게, 설명이 필요한 곳에만. 느낌표·이모지 없음.

**방향 탐색용 예시** (자유롭게 벗어나도 됩니다)
- *A. 조용한 갤러리* — 중립 팔레트, 사진 위 UI는 최소, 강조색은 한두 곳에서만.
- *B. 따뜻한 기록장* — 부드러운 표면과 여백, 모아보기·기록 같은 콘텐츠가 앞에 나오는 구성.

## 5. 제약

### 플랫폼·구현
- Android 11(API 30)+ 폰, 세로. **기준 프레임 411×891dp**(Galaxy S23, 1080×2340px). 360dp 폭에서도 깨지지 않아야 합니다. edge-to-edge(상태바·제스처 바 뒤로 콘텐츠). 이전 디자인은 428×908 프레임을 썼습니다 — 어느 쪽이든 **dp로** 적어 주세요.
- **Jetpack Compose.** 화면·컴포넌트가 코드로 1:1 옮겨질 수 있어야 합니다. 구현 비용이 큰 효과(복잡한 blur·mix-blend·파티클·그라데이션 텍스트)를 쓰면 "구현 비용 큼"이라고 표시해 주세요.
- **폰트는 앱에 번들**합니다(인터넷 권한이 없어 다운로드 폰트 불가) → **재배포 가능한 OFL 폰트만**. 현재 Gothic A1(Regular/Medium/Bold/Black). 목업은 Google Fonts에 있는 OFL 한글 폰트(Noto Sans KR · IBM Plex Sans KR · Gothic A1 · Gowun Dodum 등)로 그려 주세요. 다른 폰트를 쓰면 이름·라이선스를 적어 주세요.
- **아이콘은 벡터**(SVG → VectorDrawable). 비트맵 아이콘 금지(APK가 이미 큽니다).
- **성능.** 갤러리는 1만 장 이상을 스크롤합니다. 셀마다 그림자·블러·큰 오버레이 금지. 썸네일은 정사각 크롭.
- 화면 전환은 상태 기계 하나(내비게이션 라이브러리 없음). 전환 애니메이션은 Compose 기본 애니메이션으로 구현 가능한 범위.

### 접근성
- 터치 타깃 ≥ **48dp**. 텍스트 대비 WCAG AA(본문 4.5:1, 큰 글씨 3:1). 사진 위 텍스트·배지는 배경 처리로 대비를 확보합니다.
- 시스템 글자 크기 **200%**까지 레이아웃 유지(줄바꿈·말줄임 규칙을 명시).
- **색만으로 상태를 구분하지 않기**(선택 = 체크 + 오버레이, 위험 = 색 + 아이콘 + 문구).
- 한국어는 어절 단위 줄바꿈, 긴 앨범 이름은 1줄 말줄임. "움직임 줄이기" 설정 존중.

### 시스템이 그리는 화면 (디자인 대상 아님 — 앞뒤 흐름만)
권한 대화상자 · 휴지통 확인 대화상자(30일 복구 안내 포함) · 공유 시트. **알림**(포그라운드 서비스, 채널 "사진·영상 분석", 진행률 표시)은 디자인 대상입니다 — 지금은 시스템 기본 sync 아이콘을 씁니다.

## 7. 화면별 요청

우선순위 P0(먼저) · P1 · P2. 코드 화면 이름은 `백틱`. 문구 원문은 §8.

### S3 `Photos` — 갤러리 (P0)
- **목적**: 전체 사진·영상을 날짜순으로 훑는 홈. 분류를 몰라도 사진에 닿는 곳.
- **요소**: 제목 "갤러리" + 부제(개수 · 분석 진행/완료) · 설정 진입 · 미디어 필터 · 검색 진입("말로 찾기") · 모아보기(묶음마다 사진·영상 3개 이상일 때만 생김: "이번 주 사진·영상", "N년 전 오늘") · 정리 제안 카드(겹치는 항목이 있을 때만) · 월별 이동(사진을 다 불러오지 않고 그 달로 점프) · 날짜 머리글("9월 25일 · 사진 1장 · 영상 1개") · **3열 정사각 그리드**(전체 폭, 간격 3dp, 셀 ≈135dp) · 영상 셀(▶ + 길이) · 즐겨찾기 표시 · 300개씩 이어 붙이기.
- **상태**: 기본 · 영상 필터 · 분석 중(부제에 진행) · **영상 분석 진행 표시** · 비어 있음 · 일부 허용(배너) · 선택 모드 · 영상만 있음.
- **새 요구**
  1. 스크롤 전 첫 화면에서 그리드가 **화면 높이의 60% 이상**.
  2. 모아보기·정리 제안·검색·월 이동의 위치와 접힘 방식을 제안해 주세요(스크롤과 함께 접히는 헤더, 고정 검색 아이콘, 월 스크러버 등).
  3. 날짜 머리글 압축(항목이 적은 날 묶기 등).
  4. 영상 셀 디자인: 배지 위치·길이 표기·가독성. **세로/가로/정사각** 영상 모두, 썸네일이 실패한 경우의 기본 카드.
  5. 영상 분석이 백그라운드에서 도는 동안의 **비침습 진행 표시**(예: "영상 42/184개 · 장면 분석 3/8").
- **데이터 예**: 2,019개 = 사진 1,835 + 영상 184. 월 칩 수십 개. 촬영 시각이 없는 항목은 맨 뒤 "날짜 미상".

### S3-a `Photos/selecting` — 선택 모드 (P0)
- 길게 눌러 진입. 헤더가 "N개 선택" + "화면에 불러온 111개 중에서" + 선택 해제(✕) + 전체 선택/선택 해제로 바뀌고, 탭 바가 숨겨지며 하단에 액션 바가 나옵니다.
- **하단 액션**: 즐겨찾기 · 공유 · 앨범에 추가 · (앨범 상세에서만) 앨범에서 빼기 · **휴지통으로**(N개).
- **새 요구**: '빼기(가벼움)'와 '휴지통(무거움)'을 색·아이콘·위치·확인 방식으로 확실히 구분. 주 동작/보조 동작 위계. **사진과 영상이 섞인 선택**. "전체 선택은 화면에 불러온 것만"이라는 범위를 사용자가 알 수 있게(지금은 헤더 부제).

### S4 `Albums` — 앨범 (P0) ★새 기능 포함
- **목적**: 앨범 탐색. 4종 + 즐겨찾기, **사진/동영상 따로 분류해 보기**.
- **요소**: 제목 · 미디어 필터(전체/사진/동영상) · 종류 필터(전체/내 앨범/폴더/AI 분류/기록) · 종류별 섹션(제목 + 한 줄 설명) · 앨범 카드(정사각 표지, 종류 배지, 제목, 개수 문구) · AI 앨범의 축 필터(전체/인물/여행/문서/음식/순간) · 빈 상태.
- **개수 문구 규칙**

  | 보기 | 문구 |
  |---|---|
  | 전체 — 사진·영상 섞임 | `95개 · 영상 13` |
  | 전체 — 영상뿐 | `영상 13개` |
  | 전체 — 사진뿐 | `14개` |
  | 동영상 | `영상 12개` |
  | 사진 | `사진 82장` |
- **동작**: `동영상`을 고르면 목록의 모든 카드가 영상 기준으로 바뀝니다 — 영상이 없는 앨범은 사라지고, 개수·표지도 영상으로. 앨범 안(`Category`)에서도 같은 컨트롤로 전환합니다.
- **새 요구**
  1. 미디어·종류·축 필터의 위계를 다시 짜 주세요(칩 3줄 → 더 단순하게). **"동영상 분류" 진입이 1탭**이고 **지금 어느 보기인지 항상 보여야** 합니다.
  2. 카드의 영상 표현: 표지가 영상일 때, 영상 수 병기.
  3. 종류별 시각 차이: 내 앨범(사용자가 만듦) · 폴더(저장 위치) · AI(자동) · 기록(시간) — **누가 만든 묶음인지** 보이게.
  4. (제안 가능, '제안'으로 표시) 앨범 탭의 "새 앨범" 진입 — 지금은 선택 모드의 "앨범에 추가" 시트에서만 만들 수 있습니다.
- **데이터 예**: AI 앨범 5~30개 · 폴더 3~15개(3개 미만은 숨김) · 기록 최대 60개 · 내 앨범 0~N개. 라벨은 §8.

### S5 `Category` — 앨범 상세 (P0)
- **요소**: 뒤로 · 제목 · 부제("AI 앨범 · 영상 2개") · 헤더 버튼 · 미디어 필터 · 날짜별 그리드(300개씩, "N / M개 불러옴") · 선택 모드 연동 · 빈 상태("이 앨범에는 동영상이 없습니다.").
- **앨범 종류마다 가능한 동작이 다릅니다**

  | 종류 | 분류 수정 | 앨범 삭제 | 앨범에서 빼기 |
  |---|---|---|---|
  | AI 앨범 | ○ | × | ○ (태그만 뗌) |
  | 내 앨범 | × | ○ (사진·영상은 그대로) | ○ |
  | 즐겨찾기 | × | × | ○ (즐겨찾기 해제) |
  | 기기 폴더 | × | × | × (우리가 정한 묶음이 아님) |
  | 기록 | × | × | × |
- **새 요구**: 헤더 버튼 3개가 칩 모양 — 우선순위 정리(더보기 메뉴 등). 종류별로 없는 동작은 아예 숨김.

### S6 `Fix` — 분류 수정 (P2)
- 잘못 묶인 항목을 골라 **다른 AI 앨범으로 옮기거나 이 앨범에서 뺍니다.** 어느 쪽이든 파일은 기기에 그대로 남습니다(이 안내가 핵심).
- **요소**: 설명 문구 · 3열 그리드(선택) · "다른 앨범으로 옮기기" 칩(상위 6개) · 하단 "N개 이 앨범에서 빼기".
- **새 요구**: 대상 앨범 선택 UI 개선(지금은 6개 칩), 결과 되돌리기.

### S7 `Viewer` — 사진 (P0)
- **요소**: 상단(뒤로 · 날짜/시각[+ " · 파일 시각"] · "2 / 111" · 즐겨찾기) · 사진(좌우 스와이프, 핀치·더블탭 확대 1~6배) · 하단(공유 · 정보 · 휴지통) · **정보 패널**(이 사진·영상의 분류 칩[누르면 "고정"] · 안내문 · "상세 정보" 접기: 장면/출처/파일/카메라/위치/크기/선명도 — 위치는 좌표 숫자이고 장소 이름은 아직 없음, 선명도도 숫자).
- **새 요구**: 콘텐츠 몰입(컨트롤 자동 숨김/탭으로 표시) · 정보 패널의 위계 · 사진 위 컨트롤의 대비 · (제안 가능) 아래로 밀어 닫기 같은 제스처.
- **상태**: 확대 중(컨트롤 숨김) · 정보 열림 · 날짜 없음 · 로딩.

### S8 `Viewer` — 영상 (P0) ★새 기능 포함
- 사진 뷰어와 **같은 뼈대**(상단·하단 액션 위치 동일) + 재생.
- **현재 모습**: 시스템 기본 컨트롤 — 되감기(5초) · 재생/일시정지 · 빨리 감기(15초) + 탐색 막대 + 경과/전체 시간 — 이 영상 아래에 붙고, 음소거·전체 화면 알약이 영상 우상단에 얹혀 있습니다(캡처 10).
- **요소**: 재생/일시정지 · 탐색 막대와 시간(현재/전체) · 음소거 · 전체 화면(가로 강제, 시스템 바 숨김) · **찾은 장면 칩**("찾은 장면 [약 0:36] [약 0:15] [약 0:51]" — 검색에서 열었을 때 최대 3개, 누르면 그 시각으로 이동해 재생).
- **동작**: 첫 진입은 일시정지 + 컨트롤 표시. 검색 결과·저장한 앨범에서 장면으로 열면 **그 장면부터 자동 재생**. 앱이 백그라운드로 가면 일시정지하고, 재생 중이었다면 돌아왔을 때 그 위치에서 이어서 재생.
- **상태**: 일시정지 · 재생 · 음소거 · 전체 화면 · 장면으로 열림 · 긴 영상(`1:02:03`) · 세로/가로 영상 · 재생 불가("이 기기에서 재생할 수 없는 동영상입니다.").
- **새 요구**: 재생 컨트롤을 **앱 톤에 맞게 커스텀 디자인**(지금은 시스템 기본 컨트롤). (제안 가능) 탐색 막대 위에 '찾은 장면' 위치 마커.

### S9 `Search` — 검색 (P0) ★새 기능 포함
- **요소**: 입력("사진·영상 속 장면 찾기") · 추천 칩(`동영상만` 토글 + 추천 문장 + 자주 나오는 분류 이름) · **해석 칩**("시간: 작년", "시간: 여름", "태그: 반려동물" — 앱이 문장을 어떻게 이해했는지 보여 줌) · 요약 카드("검색 요약" 라벨 + 문장 + [앨범으로 모으기] + 안내). 문장 형식은 "[기간], [해석 라벨…] · 사진 N장 · 영상 M개 찾았습니다." — 예: "2025.6 – 2025.8, 작년, 여름 · 사진 12장 · 영상 7개 찾았습니다." · 결과 그리드(3열) · 검색 중 · 빈 결과 · 초기 안내.
- **영상 결과 카드**: 영상의 첫 화면이 아니라 **맞은 장면의 프레임** + `약 0:45 외 2곳`. 누르면 그 장면부터 재생. 영상은 5초 간격 프레임으로 찾으므로 시각은 근사입니다.
- **확인 모드 (앨범으로 모으기)**: 결과가 **모두 선택된 상태**로 진입 → "앨범에 넣지 않을 결과를 눌러 빼세요." → 이름 입력(기본값 = 검색어) → [N개로 앨범 만들기] / [취소]. **자동 저장 없음.** 저장하면 영상은 맞은 장면 시각도 함께 저장되고, 나중에 앨범에서 열어도 그 장면부터 재생됩니다.
- **새 요구**
  1. 입력·해석·요약·결과의 정보 위계(지금은 한 줄기 스크롤).
  2. **영상 장면 카드** 디자인(프레임 + 시각 + 여러 장면).
  3. 확인 모드가 일반 선택 모드와 확실히 구별되고 "지금 앨범을 만드는 중"임이 보이게.
  4. **결과 신뢰도 표현**: 지금은 관련도가 낮은 결과도 최대 120개까지 이어집니다. '가장 관련 높은 결과'와 '그 밖의 결과'를 구분하는 표현을 제안해 주세요(점수를 %로 보이지 말 것).
  5. 키보드가 올라온 상태의 레이아웃. 탭 화면인데 뒤로 화살표가 있는 문제 정리.
- **상태**: 초기 · 입력 중 · 검색 중 · 결과 · 빈 결과 · 확인 모드.

### S10 `Cleanup` — 정리 (P1)
- **요소**: 제목 "정리" + "겹치는 묶음 120개" · 일괄 선택 칩("보관 추천 제외하고 선택" / "전체 선택") · **묶음 카드** — 종류("완전히 같은 파일 · 2개 · 내용이 바이트까지 같습니다" / "비슷한 장면 · N장 · 연달아 찍힌 사진입니다"[사진만]) + [이 묶음은 유지] · **비교 타일**(보관 추천 = 초록 테두리 + "보관 추천 · 원본으로 보이는 파일" 또는 "보관 추천 · 가장 선명함", 나머지는 "이걸 보관"으로 보관할 것 바꾸기, 선택 원, 탭하면 크게 보기) · 하단("N개를 보내면 약 12MB가 빕니다." + [N개 휴지통으로]).
- **안전 규칙(디자인이 드러내야 함)**: 한 묶음을 모두 골라도 **한 장은 남습니다**(앱이 강제). 영상은 '완전히 같은 파일'만 묶고, '비슷한 장면'은 사진만입니다.
- **새 요구**: 나란히 비교하기 쉬운 레이아웃(확대·차이 보기) · 용량 절약 강조 · 위험 동작 위계 · 빈 상태("정리할 것이 없습니다."). **카피 교정**: "코드가 강제로 남깁니다" → 사용자 말투로.

### S11 `Settings` — 설정 (P2)
- **요소**: 뒤로 + "설정" · 상태 카드("기기 내 처리 — …" + 점) · 인덱싱 현황("2,019개 인덱싱 · AI 태그 2,017개 · 읽기 실패 2개") · "분류 항목" 토글 5개(인물/여행/문서/음식/순간 — 끄면 그 축의 AI 앨범을 숨기고 데이터는 지우지 않음) · "데이터 관리"(전체 다시 분석 / 분류 결과 전체 삭제).

| 영상 분류 태그는 영상당 **최대 5개** (프레임의 40% 이상에서 나온 것만) | 영상이 앨범 5개 안에만 들어감. 태그 칩이 길게 늘어지지 않음 |
| 촬영 시각은 **촬영 메타데이터** 또는 **파일 시각** | 후자는 "파일 시각"으로 밝힙니다. 모아보기·기록은 촬영 시각만 씁니다 |
| 검색은 **항상 최대 120개**를 관련도순으로 돌려줌(컷오프 없음). 시간·태그 조건이 먼저 걸러짐 | 결과 수가 곧 관련도가 아님 → §7 S9 새 요구 4 |
| 폴더 앨범은 3개 이상일 때만 생김. 기록은 최대 60개 | 목록 길이 상한 |
| 권한이 줄어도 **숨길 뿐 삭제하지 않음** | 앨범 카드가 0개로 남을 수 있음, 다시 허용하면 돌아옴 |
| 분석 속도(Galaxy S23 실측): 사진 1만 장 약 10분 · 영상 100개 약 3분 | 진행 화면·문구의 현실감. 영상은 사진 뒤에 이어서 처리 |
| 중복: **완전히 같은 파일**(사진·영상) / **비슷한 연속 사진**(사진만) | 영상 비교 묶음은 완전 동일만 |
| 삭제는 **OS 확인 + 30일 휴지통** | 앱 안에 "영구 삭제" 표현 없음 |

1. **색 역할 재정의**: 브랜드 · 강조/선택 · **위험(danger, 강조색과 분리)** · 성공 · 정보 · 표면 단계(3~4) · 텍스트 단계(4, **AA 이상**) · 사진 위 스크림. **다크/라이트 쌍**(§14).

## 12. 산출물과 형식

- **형식**: Claude Design 캔버스(`.dc.html`) — 폰 프레임 안의 화면들을 한 캔버스에 나란히(아트보드) + **인터랙티브 프로토타입**(F1~F4 최소). 이전 파일(`AI Gallery Auto-Sort.dc.html`)과 같은 방식이면 됩니다.
- **아트보드 이름 = 코드의 화면 이름**: `Permission` · `Analyzing` · `Photos` · `Albums` · `Category` · `Fix` · `Viewer` · `Search` · `Cleanup` · `Settings`
  + 상태 접미사: `Photos/selecting` · `Photos/video-filter` · `Photos/limited-access` · `Albums/video-only` · `Category/video-only` · `Viewer/photo-info` · `Viewer/video` · `Viewer/video-fullscreen` · `Viewer/video-scene` · `Search/empty` · `Search/results` · `Search/review` · `Cleanup/empty` · `Sheet/add-to-album` · `Toast/*`
- **화면별 최소 상태**: 기본 · 빈 · 로딩 · 선택 · 오류/제한 (해당하는 것만).
- **토큰 표**: 색·글자·간격·반경·그림자·모션을 이름 · 역할 · 값(다크/라이트) · 사용처로. 코드의 `Palette` / `Type` / `Radius`에 **1:1로 옮길 수 있게**. 값은 hex/rgba · sp · dp.
- **컴포넌트 시트**: §10-2 목록 × 상태 + 크기 스펙(dp).
- **아이콘**: 24×24 SVG 세트(파일명 영문 kebab-case) + 사용처 표.
- **앱 아이콘**: 적응형(전경/배경) + 단색 + 알림 아이콘 + (선택) 스토어용 512px + 워드마크.
- **레드라인**: `Photos` · `Albums` · `Category` · `Viewer` · `Search`에 간격·크기 표기(dp).
- **채울 이미지**: 개인정보가 없는 데모 이미지(뚜렷한 얼굴 없는 CC/생성 이미지).
- **범위 밖**: 코드 작성 · 마케팅 이미지 · 스토어 스크린샷(다음 단계).

## 16. 검수 체크리스트

- [ ] 모든 화면이 **411dp / 360dp** 폭에서 검증됨
- [ ] 글자 크기 130% · 200%에서 잘림·겹침 없음(주요 5화면)
- [ ] 텍스트 대비 AA (사진 위 배지 포함), **위험 버튼도 AA**
- [ ] 터치 타깃 48dp (칩·아이콘 버튼 포함)
- [ ] 갤러리 첫 화면(스크롤 전)에서 그리드가 높이의 **60% 이상**
- [ ] **빼기 vs 휴지통**이 색·아이콘·위치로 즉시 구분됨
- [ ] 영상 셀이 사진과 **한눈에** 구분됨 (배지 + 길이)
- [ ] **동영상 분류 보기**가 앨범 탭에서 1탭이고, 현재 보기가 항상 보임
- [ ] 영상 장면 카드가 프레임 + 시각을 함께 보여 줌
- [ ] 확인 모드가 일반 선택 모드와 구별됨
- [ ] 없는 기능(§9)이 그려지지 않음
- [ ] 아트보드 이름 규칙 준수, 토큰 표 포함
- [ ] 문구가 §8과 일치(존댓말, 단위 규칙)
- [ ] 빈 · 로딩 · 제한 상태 포함
- [ ] 아이콘 전부 벡터 24dp, 사용처 표 포함
